# Rhétorique

Ce dossier rassemblera les observations sur la composition, les reprises, les symétries, les pivots et les structures d'ensemble.

## Éléments prévus

- Structures concentriques
- Correspondances entre passages
- Pivots narratifs et argumentatifs
- Reprises lexicales
- Effets de contraste
- Organisation des séquences
